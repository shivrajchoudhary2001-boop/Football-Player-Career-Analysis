## 📌 Project Overview

This project focuses on analyzing football player data using Python to understand player performance, career statistics, and important trends.

The project includes data cleaning, exploratory data analysis (EDA), and visualization to extract meaningful insights from football datasets.

**This project was completed as part of my Data Analyst Internship at Sportskeeda.**
